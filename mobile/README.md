# Client mobile Flutter

Le dépôt source fourni ne contenait pas de projet Flutter. Ce dossier réserve l’emplacement du futur client mobile natif.

Avant d’ajouter une application Flutter, fournir le projet existant ou valider une nouvelle implémentation mobile avec le SDK Flutter et les cibles Android/iOS correspondantes. Aucun APK ou AAB n’est généré par le frontend web.
