# Mobile Flutter

Le web et le backend sont prêts dans `frontend/` et `backend/`. Le client Flutter reste à intégrer : aucune source Dart, aucun `pubspec.yaml` et aucun projet Android/iOS n’étaient présents dans l’archive initiale.

Pour produire un APK ou un AAB, ajouter le projet Flutter dans `mobile/`, connecter les variables Supabase propres au client mobile, puis valider les builds Android et iOS sur leurs environnements respectifs.
